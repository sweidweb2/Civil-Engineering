# Features by Role

Source: locked batches 1–8. Lists only.

---

## Guest / Visitor

- Browse marketplace (no account)
- Search / filter providers, listings, workers, location
- View approved providers and verified workers
- View listing prices, specs, contact, location
- Contact provider/worker outside the platform

---

## Client (registered)

- Everything a guest can do
- Register (needs Admin approval)
- Leave reviews / ratings
- Report content
- Favorite providers, workers, materials, equipment
- No project create
- No orders / checkout / hire / rent on platform

---

## Worker

- Register (needs Admin approval)
- Request verification (Unverified → Requested → Verified)
- Own profile: photo, profession, skills, bio, CV, portfolio, rates, availability, visibility
- Publish / hide profile
- Appear in public marketplace only when verified
- Publish contact info
- Leave reviews / ratings
- Report content
- Favorite directory items
- Delete own profile
- Limited project access when invited: accept/reject invite, view own tasks only (see [Project Worker Invites & Tasks](../../[3]%20Decisions/[17]%20Project%20Worker%20Invites%20%26%20Tasks.md)); no budget, docs, full team, or PM tools

---

## Provider owner

- Register (needs Admin approval; invisible until approved)
- Own company profile
- Publish / edit listings: materials, equipment, services, prices, informational quantity
- Active / Inactive listings
- Create provider categories
- Publish contact (phone, WhatsApp, email, website, address)
- Publish location
- Invite company users (owner only)
- Full company / listing data
- Leave reviews / ratings
- Report content
- Favorite directory items
- No orders inbox, accept/reject, checkout, or delivery tracking

---

## Provider user (invited)

- Full access to that provider’s company / listing data
- Cannot invite other users
- Same marketplace browse / review / report as any registered user

---

## Project Manager (collaborator)

- Register (needs Admin approval)
- Browse marketplace; use listings as planning reference
- Same complete project data as owner
- Overview, team, tasks, progress
- Plan / reference materials, workers, equipment
- Snapshot marketplace prices into project (no auto-update)
- Track material qty: purchased, used, wasted, remaining
- Add virtual workers (no platform account)
- Record actual expenses
- Record off-platform payments (informational)
- Optional budget, revenue, profit
- Planned vs actual + variance
- Cost breakdown dashboard
- Documents, photos / media, financial attachments
- Reports
- Leave reviews / ratings
- Report content
- Favorite directory items
- No orders, rental booking, payment processing, in-app hire

---

## Project Owner

- Everything a PM collaborator can do
- Create projects (private)
- Add / remove PM collaborators
- Transfer ownership to another PM
- Delete project (permanent)
- Reopen completed → active
- Restore archived
- Set project currency
- Invite platform workers to a project (PENDING → accept/reject); manage project tasks (see [Project Worker Invites & Tasks](../../[3]%20Decisions/[17]%20Project%20Worker%20Invites%20%26%20Tasks.md))

---

## Admin

- Approve PM / Provider / Worker registrations
- Approve providers into marketplace
- Decide worker verification
- Suspend / reactivate users
- Delete accounts (preserve required history)
- Hide / unpublish listings and worker profiles
- Hide / remove reviews
- Remove inappropriate content
- Edit / correct platform data
- Handle reports
- Impersonate / access accounts for support
- Manage any project / user / listing when needed
- Handle owner-left / suspended projects
- Global settings: categories, currencies, units, marketplace, verification
- Platform categories
- Platform analytics (users, listings, views, reports, verification requests)
- No subscriptions, ads, featured listings, or pay-to-rank
