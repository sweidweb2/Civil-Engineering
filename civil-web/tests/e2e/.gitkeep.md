# Web E2E (Playwright)

Critical UI flows against a **running seeded API** + Vite (started by Playwright).

```bash
# Terminal 1 — infra + API (local Docker)
docker compose up -d
cd backend && npx prisma migrate deploy && npm run prisma:seed && npm run dev

# Optional if auth logins start returning 429:
docker exec civil-redis redis-cli FLUSHDB

# Terminal 2
cd civil-web
npx playwright install chromium   # first time
npm run test:e2e
# or: npm run test:e2e:ui
```

Seed accounts (password `password`): `super@`, `admin@`, `pm@`, `provider@` `@example.com`.

`auth.setup.ts` logs in once per role and writes `playwright/.auth/*.json` (gitignored) so the suite does not burn the auth rate limiter.

Coverage: public home, login/register, role homes, route guards, admin/PM/super shell navigation, PM create project + steppers landing.
