# Web E2E (Playwright)

Critical UI flows against a **running seeded API** + Vite (started by Playwright).

```bash
# Terminal 1 — API (Supabase Postgres via backend/.env)
cd backend && npm run db:migrate && npm run db:seed && npm run dev

# Terminal 2
cd civil-web
npx playwright install chromium   # first time
npm run test:e2e
# or: npm run test:e2e:ui
```

Seed accounts (password `password`): `super@`, `admin@`, `pm@`, `provider@` `@example.com`.

`auth.setup.ts` logs in once per role and writes `playwright/.auth/*.json` (gitignored) so the suite does not burn the auth rate limiter.

Coverage: public home, login/register, role homes, route guards, admin/PM/super shell navigation, PM create project.
