# Batch 7 — Admin, Moderation & Platform Rules

**Status:** LOCKED

Registration approval, worker verification (visibility, not a badge), moderation, reports, reviews, global settings, categories, admin analytics. **No monetization** in the current version.

**Marketplace correction — LOCKED:** Discover → View information → Contact externally. Read-only discovery + external contact. No subscriptions, advertising, orders, payments, hiring workflows, or rental transactions for now.

**Core Admin Principle:** Users provide the content and information; Admin controls platform trust, approval, moderation, configuration, and platform-wide integrity.

---

# BUSINESS LOGIC — LOCKED

## 1. User Approval

Admin approval is required for registered:

- Project Managers
- Providers/Companies
- Workers

Guests/visitors can browse without an account.

---

## 2. Provider Approval

A newly registered provider remains unavailable/invisible in the marketplace until Admin approval.

---

## 3. Worker Verification

Workers can request verification.

Flow:

**Unverified → Verification Requested → Verified**

Admin controls the decision.

Unverified workers are **not** displayed in the public marketplace until approved/verified according to the platform's visibility rules.

---

## 4. Verification Badge

No special verification badge is required.

Verification itself controls marketplace visibility.

---

## 5. Admin Moderation

Admin can:

- Hide/unpublish listings
- Hide worker profiles
- Suspend users
- Suspend providers
- Remove inappropriate content
- Edit/correct platform data
- Review reported content

---

## 6. User Suspension

Account lifecycle can include:

**Active → Suspended → Active**

Admin controls suspension/reactivation.

---

## 7. Account Deletion

Admin can permanently delete accounts where appropriate.

However, important historical/business records should be preserved where necessary rather than destroying historical project/financial records.

---

## 8. Provider Subscription

Not implemented / not part of the current business model.

---

## 9. PM Subscription

Not implemented / not part of the current business model.

---

## 10. Worker Monetization

Locked for now.

No verification fees or premium worker monetization for the current business model.

---

## 11. Advertising / Featured Listings

Locked for now.

No paid promotion or advertising system currently.

---

## 12. Sponsored Content

Locked for now together with advertising/promoted listings.

---

## 13. Search Ranking

Normal marketplace search should primarily use:

- Relevance
- Search criteria
- Filters
- Other legitimate marketplace attributes

It should not be pay-to-rank, since paid promotion is not currently part of the system.

---

## 14. Reports / Complaints

Users can report:

- Providers
- Workers
- Listings
- Reviews
- Other inappropriate content

Admin reviews and handles reports.

---

## 15. Reviews

Any registered account can leave reviews/ratings.

There is no requirement for a platform-recorded transaction because the platform does not manage orders/hiring.

---

## 16. Review Moderation

Admin can hide/remove reviews that violate platform rules.

---

## 17. Global Platform Settings

Admin controls platform-wide settings such as:

- Default categories
- Worker categories
- Material categories
- Currency options
- Units
- Marketplace settings
- Verification rules
- Other global configuration

---

## 18. Categories

Two levels:

**Platform categories**

- Created/managed by Admin
- Available globally

**Provider categories**

- Custom categories created by providers where appropriate

---

## 19. Admin Analytics

Admin dashboard can show platform-level statistics such as:

- Registered users
- Active PMs
- Providers
- Workers
- Projects
- Marketplace listings
- Listing views
- Worker/provider views
- Reports
- Verification requests
- Other platform metrics

Revenue/subscription analytics are not currently relevant.

---

## 20. Business Model

No monetization/business model is locked for the current version.

Future possibilities can be discussed later without affecting the current architecture/business logic.

---

## Boundary

The marketplace remains:

**Read-only discovery + external contact.**

No subscriptions, advertising, orders, payments, hiring workflows, or rental transactions for now.
